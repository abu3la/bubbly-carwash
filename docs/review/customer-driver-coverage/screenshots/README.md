# لقطات الواجهات

التقطت من الكود الحالي داخل محاكي iPhone. الأشخاص والحجوزات وأرقام الفلل وحدود المعاينة بيانات اختبار، وليست تغطية تشغيلية معتمدة. لم تُعدّل صور الواجهات أو تُولّد بالذكاء الاصطناعي.

## التحقق أثناء الالتقاط

جرّبت النقر على مهام السائق، متابعة المهمة، فتح البلاغ، الانتقال بين الحساب والرئيسية، تبديل لغة العميل، الباقات الشهرية وتغيير التكرار من 2 إلى 3، تسجيل الخروج والعودة للانبوردنق، التنقل بين صفحاته الثلاث، ثم تسجيل الدخول مجددًا. صُحّحت مشكلة إعادة تركيب التنقل عند تسجيل الخروج وصياغة عدد المواعيد. فحوص TypeScript وESLint للتطبيقين ناجحة بعد الإصلاح.

هذه معاينة واجهات. لا تثبت تشغيل ترحيل قاعدة البيانات أو التكامل مع الدفع والكاميرا الفعلية أو اعتماد النطاق الجغرافي الحقيقي.

لقطة لوحة التحكم لم تُلتقط: توقف طلب تشغيل خادم المعاينة المحلي عند الصلاحية. لا توجد صورة للداشبورد ضمن هذه المجموعة.
