# Interface work

Read [DESIGN.md](DESIGN.md) before changing any interface. Verified Bubbles design files and assets referenced there take precedence over general design preferences and historical design guidance when they conflict; preserve clarity and accessibility. Never infer missing reference values or replace approved fonts/assets with lookalikes. Respect the documented pilot scope and shared-component impact; if the approved source is unavailable, report the missing dependency before styling from assumptions.
