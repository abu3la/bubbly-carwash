# Bubbly Carwash

Monorepo: Hono/Workers API + Supabase (apps/api), Expo client-app and
driver-app, Vite dashboard, Next.js landing. Shared code in libs/.

## Design work

Before building or changing ANY UI (mobile, dashboard, or landing), read
`docs/DESIGN_SYSTEM.md` and follow it. It defines the brand world, the
signature waterline motif, token rules, component build order, and the
definition of done. Use tokens from `@bubbly/design-tokens` only - no
hard-coded colors, sizes, radii, or durations in components.
